# Oops-through-python

Python OOP practice programs (Code-1 to Code-27).

## Topics Covered

### 1. Classes and Objects
- Creating classes
- Creating objects
- Accessing attributes and methods

### 2. Methods
- Instance methods using `self`
- Methods with parameters
- Variable-length arguments (`*args`)

### 3. Constructors
- Default constructor
- Parameterized constructor (`__init__`)
- Multiple objects with different values

### 4. Variables
- Class variables
- Instance variables

### 5. Inheritance
- Single inheritance
- Multilevel inheritance
- Multiple inheritance

### 6. Polymorphism
- Method overriding

### 7. Basic Python Concepts
- User input with `input()`
- Type conversion with `int()`
- Arithmetic operators
- Comparison operators
- String concatenation and repetition

## Programs Included
- Rectangle (area and volume)
- Student (name, age, branch)
- Animal, Dog and Cat
- Father, Mother and Child
- Demo and Sample classes

## Run
```bash
python Code-1.py
```
